음악 타임라인 생성기

MP3와 WAV 파일을 여러 개 불러오면 재생시간을 읽어 유튜브 설명란용 누적 타임라인을 만듭니다. 타임라인 생성 자체는 파일을 서버로 보내지 않고 브라우저 안에서만 처리됩니다. 다만 아래 "실제 파일명 변경" 기능(ZIP 다운로드, 폴더 내 실제 rename)을 쓸 때만 Creator Studio 서버(로컬)가 관여합니다 — ZIP은 파일 내용을 서버로 보내 다시 받는 방식이고, 폴더 rename은 파일 내용을 전혀 옮기지 않고 서버가 그 폴더의 실제 파일명만 바꿉니다.

MP3 또는 WAV 파일을 끌어놓으세요 클릭해서 여러 파일을 선택할 수도 있습니다.

순서 제목 괄호 제목 파일 형식 길이 이동 삭제

길이가 잘못 인식된 경우 '길이' 칸을 MM:SS 또는 HH:MM:SS 형식으로 직접 수정할 수 있습니다. '연번 자동 부여'가 켜져 있으면 제목 앞 번호는 순서가 바뀔 때마다 자동으로 다시 매겨집니다.

괄호 제목은 타임라인 출력과 CSV에만 들어갑니다. 실제 파일명 변경(ZIP·폴더 rename)에는 영향을 주지 않습니다. AI 채우기는 Gemini 키가 있어야 하며, 결과는 언제든 직접 고칠 수 있습니다.

실제 파일명 변경 브라우저는 로컬 파일명을 직접 바꿀 수 없어, 아래 두 방법은 이 Creator Studio 서버가 대신 처리합니다.

① 연번 ZIP 다운로드 (서버 설정 없이 바로 가능)

지금 목록의 순서·연번대로 파일명을 바꾼 사본을 ZIP으로 묶어 다운로드합니다. 원본 파일은 그대로 둡니다.

② 실제 파일명에 연번 적용 (주력)

WAV/MP3 원본이 들어있는 폴더 경로를 입력하면, 그 폴더의 실제 파일명을 지금 목록의 연번대로 바꿉니다. 반드시 미리보기를 확인한 뒤 [적용]을 눌러야 실행됩니다.

⚠️ 아직 아무것도 바뀌지 않았습니다. 아래 미리보기를 확인한 뒤 [적용]을 눌러야 실제 파일명이 바뀝니다.
